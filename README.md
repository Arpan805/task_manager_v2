#  CLI TASK MANAGER

This is my first Python project, developed to practise core Python concepts and implement basic task management with JSON file storage.

## Features

- Add Tasks: Add new tasks with automatically generated unique IDs.
- View Tasks: Display all available tasks.
- Complete Tasks: Mark tasks as completed using their IDs.
- Delete Tasks: Delete tasks using their IDs.
- Search Tasks: Search for tasks by title.
- JSON Storage: Save and load tasks using a JSON file.
- Input Handling: Handle invalid menu inputs.

## Technologies Used

- Python
- JSON
- OS
